# SEVORA website

Live site: https://sevora-ai.netlify.app

This repository is the built website. Netlify publishes it automatically on every push to `main`.
The source and build scripts live in Claude's workspace; changes are built there and pushed here.

- `index.html` and the other pages: the main site
- `demos/`: the live AI demos (Business Autopilot, Decision Desk, Voice Desk and six WhatsApp desks)
- `work/`: the six immersive website demos
- `media/`: images and videos
